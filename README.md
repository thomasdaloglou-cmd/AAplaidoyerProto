# AA Plaidoyer Proto

Prototype interactif du plaidoyer Apprentis d'Auteuil.

## Publication avec GitHub Pages

1. Mettre `index.html` à la racine de la branche `main`.
2. Dans GitHub : Settings > Pages.
3. Dans "Build and deployment", choisir "Deploy from a branch".
4. Sélectionner la branche `main` et le dossier `/(root)`.
5. Enregistrer.

Le prototype actuel est autonome : styles, scripts et images sont intégrés directement dans `index.html`.
